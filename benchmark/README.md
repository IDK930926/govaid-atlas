# Final Benchmark

See [the benchmark protocol](../docs/benchmark-protocol.md) for case definitions, Gold Answer provenance, scoring, adjudication, and regression safeguards.

## Cases

`cases.json` defines ten fixed synthetic cases and their implementation-grounded Gold Answers. Its shared `evidenceContext` lists the official sources, and each case's `evidenceIds` identifies the applicable source(s):

| Case | Coverage |
|---|---|
| B01 | Central rules pass |
| B02 | `ownsHome=true` fails |
| B03 | `receivesOtherHousingAid=true` fails |
| B04 | Unknown `ownsHome` is uncertain |
| B05 | Unknown other housing aid is uncertain |
| B06 | New Taipei local condition is unknown |
| B07 | New Taipei local condition is true |
| B08 | Taipei `centralRentApproved` is unknown |
| B09 | Taipei `centralRentApproved` is true |
| B10 | Synthetic policy conflict requires human review |

`results.csv` contains the existing recorded benchmark results; do not overwrite or regenerate them. The manual worksheet at `manual-results.csv` contains blank rows for human completion only.

## Run

From the repository root in PowerShell:

```powershell
# GovAid Atlas deterministic method
npm exec -- tsx src/benchmark-runner.ts --method GOVAID_ATLAS

# LLM + Policy Context baseline (requires local Ollama and qwen3.5:4b)
npm exec -- tsx src/benchmark-runner.ts --method LLM_CONTEXT

# Summarize populated rows in benchmark/results.csv, grouped by method and Run ID
npm exec -- tsx src/benchmark-runner.ts --summary

# Export the latest existing LLM_CONTEXT run for human unsupported-claim review
npm exec -- tsx src/benchmark-runner.ts --export-llm-adjudication
```

Each benchmark run appends only the rows from that explicitly requested run. The LLM baseline calls Ollama directly; it does not use Atlas's Agent provider/orchestrator or decision components. There is no retriever in this baseline, so it is not called RAG. `Unsupported Claim` for an LLM result remains `REVIEW` until a human adjudicates it. The adjudication export copies saved answers and starts every review as `REVIEW`; it does not call the model or modify `results.csv`, and it refuses to overwrite an existing review file. For manual evaluation, fill actual answers and measurements in `manual-results.csv`; no manual answers are autogenerated. Copy completed rows into `results.csv` to include them in the summary.

Unsafe Certainty is calculated only over B04, B05, B06, B08, and B10. The current GovAid Atlas runner measures deterministic evaluation only, not the complete Agent workflow; its completion time is `N/A` and must not be compared with the LLM's end-to-end response time.
